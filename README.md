# Java Calculator

A simple command-line calculator built in Java 

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Division-by-zero handling
* Continuous calculations using a loop-based menu

## Concepts Practiced

* Classes and methods
* Static methods
* User input with `Scanner`
* Loops (`while`)
* Conditional logic
* `switch` statements
* Method decomposition
* Return values
* Formatted output using `printf`

## Running the Program

Compile:

```bash
javac -d bin src/Calculator.java
```

Run:

```bash
java -cp bin Calculator
```
